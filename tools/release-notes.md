## Install or update

Castle Story Plus runs on the Unity 6 port: Castle Story on a current Unity, made from your own Castle Story install the
first time it starts (you must own the game on Steam; nothing of the game is in the package). Download the package for
your system below. Each one is complete: installer, the port and Castle Story Plus.

- **Windows:** `CastleStoryPlus-<version>-windows.zip`. Unpack it and double-click `install.bat`.
- **Linux:** `CastleStoryPlus-<version>-linux.zip`. Unpack it and run `bash install.sh`. If Steam is closed, the installer also sets the game's launch option. Otherwise set it once yourself (right-click Castle Story > Properties > Launch Options): `./run_bepinex.sh %command%`

The installer finds Castle Story in your Steam libraries and puts the port in its folder (`CastleStoryPlus-Unity6`);
Play in Steam then starts the port. The first start converts the game (a minute or so). If you had Castle Story Plus
0.8.0 or older, "Update" in the main menu moves you over to the port by itself. Saves and settings are shared with the
original game. Once installed, the game tells you in the main menu when a new version is out and can update itself.
